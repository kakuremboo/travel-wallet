旅行おこづかい管理 v1.0（試作版）

【利用方法】
1. このフォルダに含まれる5ファイルを、HTTPS対応の静的Webホスティング（GitHub Pages、Netlify等）へ同じディレクトリにアップロードしてください。
2. iPhoneのSafariで公開URLを開き、共有 →「ホーム画面に追加」でアプリ風に使えます。
3. 初回はインターネットに接続して開き、次回以降はオフラインでも利用できるよう設計しています。旅行前に機内モードで起動・記録を試してください。
4. 行事を作成 →「設定・保存」で参加者と預かり金を登録 →「支出入力」で記録 →「精算」で返金します。
5. JSONバックアップをiPhoneの「ファイル」等に定期保存してください。

【重要】
- 同じiPhone・同じブラウザ環境にデータを保存します。Safariのサイトデータ消去、アプリ削除、端末破損で消えることがあります。
- 履歴から取り消しできますが、元データは取消済みとして残ります。取消記録はバックアップにも保存されます。
- 複数名のまとめ買いでは「1人あたりの同額」を記録します。異なる金額の場合はそれぞれ入力してください。
- 現金照合は直近の記録です。支出や返金後には再確認してください。
- 帳簿と実際の財布の残高が一致するか、旅行前後で確認してください。
- 個人情報を含みます。公開URLが第三者に知られてもサーバーにデータは送られませんが、端末やバックアップの保護に注意してください。
- HTTPSでの設置前にindex.htmlだけを開く方法はiOSの保存・オフライン動作が不安定なため推奨しません。
- この版は試作です。重要な現金管理に本番使用する前にテストデータで操作・記録・バックアップ・復元・精算を検証してください。
